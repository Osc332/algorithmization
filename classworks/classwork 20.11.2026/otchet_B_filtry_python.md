4. Оценка решения
Какие структуры Python здесь были уместны и почему: _Списки для итерации и хранения результата, словари для удобного доступа к полям товара по ключу._
Где в решении проявились списки: _Входной массив данных и результирующий список `result`._
Где понадобились словари или доступ по ключу, если они использовались: _Для чтения полей `price` и `title` у каждого товара._
Оцените сложность одного прохода по `n` товарам с `k` проверками: _O(n * k), где k — количество активных фильтров (обычно k=2, поэтому фактически O(n))._
Что интервьюер уточнил или исправил: _Предложил использовать `continue` для инверсии условий, чтобы избежать вложенных блоков `if` и сделать код более плоским и читаемым._
