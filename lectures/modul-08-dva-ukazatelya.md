## Содержание модуля

### Техника

**Указатель** — переменная с номером позиции в списке, которая меняется
по правилу алгоритма. **Два указателя** — проход, в котором два индекса
двигаются по данным и на каждом шаге сдвигается хотя бы один. Три формы:

| Форма | Как двигаются | Где применяется |
|---|---|---|
| навстречу | с двух концов к середине | пара с суммой в отсортированном списке, разделение по порогу |
| в одну сторону | один читает, другой пишет | удаление повторов, сжатие, перенос нулей |
| по двум последовательностям | по указателю на каждую | поиск подпоследовательности, слияние |

Признаки в условии: «отсортирован», «пара», «сумма двух» — указатели
навстречу; «на месте», «верните длину», «подряд» — в одну сторону;
«за один проход», «O(n)» — перебор не подходит.

### Пара с заданной суммой

Перебор проверяет все n·(n − 1)/2 пар — `O(n²)`. В отсортированном списке
указатели ставят на концы: если сумма меньше target, сдвигают левый,
если больше — правый.

```python
i, j = 0, len(a) - 1
while i < j:
    s = a[i] + a[j]
    if s == target:
        return (i, j)
    if s < target:
        i += 1
    else:
        j -= 1
return None
```

**Инвариант:** если пара с суммой target есть, она лежит на участке
с i по j. Каждый шаг исключает один элемент, указатели не возвращаются
(**монотонность**), поэтому шагов не больше n − 1: `O(n)` времени и `O(1)`
памяти. Условие `i < j` не даёт взять один элемент дважды.

### Чтение и запись

```python
w = 0
for r in range(len(a)):
    if оставить(a[r]):
        a[w] = a[r]
        w += 1
del a[w:]
return w
```

Указатель записи никогда не обгоняет указатель чтения (`w ≤ r`), поэтому
запись не затирает непрочитанное. Так решаются удаление повторов
в отсортированном списке и сжатие серий (RLE). Для переноса нулей в конец
вместо записи делают обмен.

### Разделение

**Разделение** (partition) — перестановка на месте: сначала элементы,
для которых условие верно, затем остальные. Его можно сделать указателями
в одну сторону (сохраняется порядок) или навстречу (меньше обменов).
Условие цикла `i <= j` — когда каждый элемент нужно отнести к группе.

### Ошибки

| Ошибка | Результат |
|---|---|
| `<=` вместо `<` в задаче о паре | пара из одного элемента `(k, k)` |
| перепутаны ветки сдвига | `None` при существующей паре |
| запись вместо обмена при переносе нулей | нули пропадают |
| цикл по парам соседей | пропущен последний элемент |

### Замер

Перебор при удвоении n замедляется в 4 раза, указатели — в 2 раза.
Решение через словарь — `O(n)` времени и `O(n)` памяти. Сортировка плюс
указатели — `O(n log n)`.
