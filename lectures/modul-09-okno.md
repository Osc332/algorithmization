## Содержание модуля

### Окно

**Подотрезок** (подмассив) — элементы, которые стоят подряд; в Python это
срез `a[l:r]`. **Окно** — подотрезок, заданный полуинтервалом `[l, r)`,
его длина `r − l`. **Скользящее окно фиксированного размера** проходит
список с шагом в одну позицию; окон длины k в списке из n элементов —
n − k + 1.

Признаки в условии: «длины k», «за k минут», «подряд», «подмассив»,
«подстрока». Если числа k нет, а длину задаёт условие («сумма не меньше S»,
«без повторов»), это окно переменной длины — следующая тема.

### Пересчёт за O(1)

Сумма каждого окна срезами стоит `O(n·k)`: каждый срез копирует k элементов.
**Сдвиг окна** пересчитывает ответ по двум элементам: прибавить пришедший,
вычесть ушедший.

```python
total = sum(nums[:k])
best = total
for r in range(k, len(nums)):
    total += nums[r] - nums[r - k]
    best = max(best, total)
```

`r` — пришедший элемент, `r − k` — ушедший. Время `O(n)` при любом k,
память `O(1)`. Ответ для текущего окна, который исправляется при сдвиге,
называют **состоянием окна**: сумма, счётчик гласных, число нужных
элементов. Максимум окна так не пересчитать.

### Лучший отрезок длины k

Лучшее окно ищут на ходу, сравнивая каждое новое окно с лучшим. Равные
суммы: знак `>` оставляет самое левое окно. Отрицательные числа: начальное
значение — сумма первого окна; с нулём ответ будет неверным. Похожие задачи: наибольшее среднее
(LeetCode 643), наибольшее число гласных в подстроке (LeetCode 1456).

### События во временном окне

Окно `[s, s + w)` на оси времени: число событий в нём меняется.

```python
l = 0
for r in range(len(times)):
    while times[r] - times[l] >= w:
        l += 1
    best = max(best, r - l + 1)
```

Указатель `l` только растёт (монотонность), поэтому вложенный `while`
не делает решение квадратичным: всего `O(n)`.

### Границы

При k = 1 окна совпадают с элементами. При k = n окно одно, цикл сдвига
не выполняется. При неверном k (0, отрицательное, больше n) и пустом списке
функция бросает `ValueError` до работы с окнами — так записано в контракте.

### Ошибки

| Ошибка | Где |
|---|---|
| `nums[r − k + 1]` вместо `nums[r − k]` | вычитается не тот элемент |
| первое окно не учтено в ответе | сравниваются только окна после сдвига |
| `best = 0` при отрицательных числах | ответ 0 вместо отрицательной суммы |
| `>=` вместо `>` | возвращается не самое левое окно |
| `r − l` вместо `r − l + 1` | длина окна на единицу меньше |

### Замер

Срезы — `O(n·k)`: при k = 100 время растёт вдвое при удвоении n, при
k = n/2 — вчетверо. Сдвиг — `O(n)` при любом k. Копирование элемента
в срезе дешевле шага цикла Python, поэтому при малых k разница меньше,
чем следует из оценки.
