## Содержание лекции

Занятие продолжает тему 3: оценку по коду проверяют запуском. Порядок
работы в каждом опыте: прогноз → запуск → замер → сравнение → объяснение.

### Замер времени

`time.perf_counter()` возвращает время с высоким разрешением; разность
двух вызовов — длительность участка кода. Один запуск ненадёжен: на время
влияют фоновые процессы и кэши. Поэтому замер повторяют несколько раз
и берут **медиану** — значение в середине упорядоченного ряда; отдельные
выбросы на неё не влияют.

У очень быстрых операций сам вызов таймера и функции может занимать
больше времени, чем операция. Для них используют `timeit`: пакет из многих
операций делят на их число.

### Проверка оценок запуском

| Опыт | Ожидание при удвоении n |
|---|---|
| обращение по индексу, `O(1)` | время не растёт |
| линейный поиск, `O(n)` | время растёт примерно вдвое |
| перебор пар, `O(n²)` | время растёт примерно вчетверо |
| поиск в `list` и в `set` | список растёт с n, множество — нет |

Один замер не устанавливает класс сложности: вывод делается по анализу
кода, а замер его подтверждает или показывает расхождение.

### Замер памяти

`tracemalloc` отслеживает память, которую выделяет Python, и показывает
пик. Время и память измеряются в разных запусках, чтобы трассировка
не замедляла таймер. Деление байтов на 1024² даёт MiB.

### Список и генератор

Список хранит все n элементов сразу, его память `O(n)`. Генератор выдаёт
элементы по одному, его память `O(1)`. Поиск дубликатов двумя способами
показывает размен: вложенные циклы — `O(n²)` времени и `O(1)` памяти,
множество — `O(n)` времени и `O(n)` памяти. Поиск в готовом множестве
не требует дополнительной памяти, но само множество занимает `O(n)`.

## Что делали на занятии

1. Запустили первый замер `perf_counter` и повторили его семь раз.
2. Для `O(1)`, `O(n)`, `O(n²)` записали прогноз, затем замерили время
   при росте n и сравнили с прогнозом.
3. Сравнили поиск в `list` и `set`, суммирование двумя способами.
4. Замерили память `tracemalloc` для списка и генератора.
5. Сравнили два способа поиска дубликатов по времени и по памяти.
