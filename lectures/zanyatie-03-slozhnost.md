## Содержание лекции

### Размер входа и операция

На этом занятии сложность считают по коду. Секунды зависят от компьютера,
число операций от него не зависит. **Размер входа** n — длина списка или строки.
**Элементарная операция** — действие, ради которого написан алгоритм,
например сравнение. **T(n)** — число таких операций на входе размера n,
**S(n)** — дополнительная память, которую решение создаёт сверх входа.

### O-нотация

Запись `T(n) = O(f(n))` означает: начиная с некоторого n₀, T(n) не больше
c · f(n) для некоторой константы c. Это верхняя граница роста. Константы
и младшие слагаемые отбрасываются: `3n + 7` записывается как `O(n)`.
На маленьких входах отброшенное важно: при n = 8 решение `O(n²)` делает
28 сравнений, а `O(n log n)` — 12. При n = 1024 — уже 523 776 против 5120.

### Классы роста

| Класс | Пример | При удвоении n |
|---|---|---|
| `O(1)` | обращение по индексу | не меняется |
| `O(log n)` | бинарный поиск: отрезок делится пополам | +1 шаг |
| `O(n)` | один проход по списку | ×2 |
| `O(n log n)` | сортировка слиянием | чуть больше ×2 |
| `O(n²)` | перебор всех пар | ×4 |

На занятии каждый класс показан прогоном на n = 64: бинарный поиск делает
6 шагов, линейный проход — 64 сравнения, перебор пар при n = 24 — 276.

### Оценка по коду

| Что в коде | Как считается |
|---|---|
| два цикла подряд | складываются: n + n = `O(n)` |
| цикл внутри цикла | умножаются: n · n = `O(n²)` |
| отрезок делится пополам на каждом шаге | `O(log n)` |

Оценка берётся по **худшему случаю**: линейный поиск может найти элемент
первым, но гарантия — n сравнений.

### Строки со скрытой стоимостью

| Строка | Стоимость | Причина |
|---|---|---|
| `x in data` для списка | `O(n)` | перебор до совпадения |
| `x in seen` для множества | `O(1)` в среднем | адрес считается по значению |
| `sorted(prices)` | `O(n log n)` | сортировка сравнениями |
| `data[1:]` | `O(n)` время и память | срез копирует элементы |
| `result.insert(0, x)` | `O(n)` | остальные элементы сдвигаются |
| `sum(data)`, `max(data)` | `O(n)` | полный проход внутри функции |

Один цикл с `row not in result` внутри даёт `O(n²)`.

### Ограничение из условия

Ограничение `n ≤ 200 000` подсказывает класс решения. Ориентир — около
10⁷ простых операций в секунду: `O(n²)` при n = 200 000 даёт 4 · 10¹⁰
операций и не укладывается в лимит, `O(n log n)` укладывается.

### Как назвать сложность на секции

Одна фраза из трёх частей: «Время `O(n)` — один проход по списку; память
`O(1)` — храню только счётчик; худший случай — искомого номера нет, проход
идёт до конца».
